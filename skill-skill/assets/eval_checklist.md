# eval-checklist

- [ ] 触发时机是否合适？
- [ ] 是否提取了真正可迁移的规则？
- [ ] 是否错误吸收了临时上下文？
- [ ] 是否清晰区分了个人层和通用层？
- [ ] 是否标注了所有规则的来源？
- [ ] skill 粒度是否合适？
- [ ] 是否减少了后续的重复修改？
- [ ] 是否体现了“沉淀重复劳动、规范 skill 创建、积累个人方法资产”三层价值？
- [ ] 是否允许用户轻松删除误提取规则？
- [ ] 是否保留了版本号和维护记录？
- [ ] 是否说明了不适用场景？
- [ ] 是否明确写出了哪些能力当前刻意不做？
- [ ] 是否把提醒表述为当前工作流中的主动建议，而不是后台常驻监听？
