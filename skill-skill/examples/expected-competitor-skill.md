# Competitor Analysis Workflow

> 从竞品分析对话中抽取稳定的结构、分析维度、结论口径与输出格式，生成可复用的竞品分析 skill 草稿。

## 适用场景
- 需要多次迭代竞品分析结构与维度的产品或市场研究任务
- 希望把竞品写作框架与个人结论口径长期固定下来
- 需要统一多家竞品的对比顺序和输出格式

## 不适用场景
- 一次性市场摘录或资料搬运
- 只需要罗列功能点，不做结构化判断
- 仅针对某个客户的临时竞标材料
- 缺少可复用分析维度的临时任务
- 仍在频繁推翻分析结构的早期探索阶段

## 输入要求
- 当前任务的 transcript 或本次对话摘要
- 与任务相关的输入材料或目标输出对象
- 如需合并，额外提供已有 skill Markdown 文件

## 通用层规则（所有同类任务通用）
- 不要只列功能
- 以后竞品分析固定成四段：产品定位、目标用户、核心差异、主要风险
- 再加两个统一维度：定价模式、获客渠道
- 所有竞品都按同一顺序写，不要一家一个写法
- 格式再收紧一点，用数字编号，不要大段散文
- 每家最后补一句“我们可借鉴什么”
- 以后做竞品分析都按这个框架，除非我特别说明

## 个人层规则（你的专属工作习惯）
- 文风偏好：结论要直接，不要口号式形容词
- 结构偏好：我习惯先给一句结论，再展开维度
- 禁用表达：未明确提取
- 严谨程度：未明确提取
- 其他个人习惯：未明确提取

## 必做步骤
1. 明确竞品范围与本次排除项。
2. 固定每家竞品的分析顺序与公共维度。
3. 先给一句结论，再展开差异、风险与可借鉴点。
4. 统一编号和格式，确保不同竞品可横向比较。
